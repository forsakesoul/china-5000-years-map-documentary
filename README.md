# 中国五千年：山河流转，文明长卷

一部用程序绘制的历史地图纪录片：**22 分 57 秒**，1920×1080，34 个场景，中文解说与字幕。
画面不是实拍素材，也不是静态史图，而是按历史快照逐年逐帧生成的古地图动画——羊皮纸底色、
水墨晕渲地形、书法标注、疆域随时间衍化。

成片与配音音轨体积超过 GitHub 单文件上限，未随仓库提供，按 [docs/使用说明.md](docs/使用说明.md)
的步骤可完整重建。

## 内容结构

全片 34 场，从文明起源讲到当代发展。每场的图层、政权配色、城市点位、流线都在
`src/map_scenes.py` 里配置，与 `data/story.json` 同序对应：

| 阶段 | 场景 | 内容 |
|---|---|---|
| 序章与读图方法 | 0–1 | 山河底形；说明本片如何处理历史边界 |
| 文明起源与早期国家 | 2–3 | 粟作/稻作/旱作区域；二里头等早期中心 |
| 商周 | 4–6 | 王畿与方国；分封网络；春秋分区 |
| 战国至秦 | 7–8 | 七国竞争；统一后全境 |
| 汉 | 9–11 | 匈奴势力范围；河西走廊；两汉制度 |
| 分裂与隋唐 | 12–16 | 三国示意；人口南迁；唐的疆域衍化与藩镇 |
| 宋辽夏金 | 17–19 | 北宋、南宋、辽、金、西夏；宋代社会 |
| 元明清 | 20–27 | 蒙古诸汗国；行省；明；清代治理与近代转折 |
| 现代 | 28–33 | 无国界底图上的城市与联系；片尾说明 |

## 仓库结构

```
src/         渲染与音频脚本（现役管线）
  map_style.py       地图渲染器：底图着色、疆域、标注、装饰、逐帧合成
  map_scenes.py      34 个场景的图层配置 + 自检（python src/map_scenes.py）
  render_film.py     逐帧渲染 → 拼接 → 配音、字幕、章节封装
  export_text.py     由时间轴导出字幕 / 章节 / 解说文稿
  cloud_voice.py     云端 TTS 重新合成解说（需自备 API Key）
  audio_master.py    配音母带：逐句响度对齐 + EBU R128
  cut_narration.py   一次性脚本：剪掉画面已表达的旁白，见「关于旁白」
scripts/     素材下载（历史快照、地形瓦片）
data/        story.json（分镜与解说）、timeline.json（逐句时间轴）、geography.json（自然地理标注）
assets/      历史快照、陆地/河流矢量、高程瓦片、书法字体、许可原文、sources.json（来源与校验值）
output/      交付件：成片、配音、字幕、章节、解说文稿（大文件不入库）
docs/        使用说明
work/        渲染中间产物（不入库）
```

## 快速开始

```bash
python -m pip install -r requirements.txt
node scripts/download_assets.cjs      # 核对/补齐 assets/ 下的地图素材
node scripts/download_terrain.cjs     # 核对/补齐地形瓦片
python src/map_scenes.py              # 配置自检：快照与政权名必须真实存在
python src/map_style.py --scene 15 --out work/预览.png     # 单帧预览
python src/render_film.py --list      # 列出场景与时长
python src/render_film.py --force     # 全片渲染（约 8 分钟）
```

渲染全片需要 `output/中文解说.wav` 与 `data/timeline.json`，两者时长必须一致，脚本会先校验。
没有配音文件时，可先用 `--preview` 出无声片段，或用 `src/cloud_voice.py` 合成配音。

## 关于画面与史实

这是一部**历史概览**，不是疆界考证、逐年复原，也不是标准地图。

- **历史范围来自开放数据快照**：`assets/world_<年份>.geojson`（Historical Basemaps），
  画面圆章标注所用年份。数据集本身仍在修订，上游也建议学术使用前与其他来源比对。
- **数据缺失或明显不符史实处的处理**：用「就近分区」示意多国并立（画面注明「分区示意」），
  或按通行画法（以谭其骧《中国历史地图集》为主要参照）手绘示意范围——见
  `src/map_scenes.py` 的 `SHAPES`。涉及商、西周、春秋、战国秦与六国、统一后的秦、匈奴、
  北宋、南宋、金、西夏、辽、明；另从元的范围扣除朝鲜半岛，为清补入台湾与喀什。
- **游牧政权**没有固定疆界，画成向外晕开的势力范围，不描边。
- **疆域边界的手绘起伏**只为观感，不代表边界走向。
- **已做过的自检**：用 56 个有明确归属的地点（盘龙城、曾国、上郡、九原、辽东郡、海南、
  邓州、沙州、黑水城、可敦城、宁夏镇、河套等）逐一核对上述示意范围，修正了不符之处。
  该核对凭通行史实，未逐页比对原图，**不能替代历史地理专业审校**。
- **文化中心、城市与交通流线**是明确标注的教学示意；流线表示方向，不表示逐站复原。
- **现代章节**只使用无国界陆地轮廓与城市联系，不绘制现代主权范围。
- 正式出版、课堂严谨考证或商业公开发行前，应另行核验地图使用规范。

## 关于旁白

解说共 167 句，由云端 TTS（CosyVoice2）合成后做母带处理，非真人录音。
画面已用动态疆域表达的 5 句「取舍说明」，已从旁白、字幕与文稿中一并剪除；
若用 TTS 重新合成，这几句会重新出现，需再跑一次 `src/cut_narration.py`。

## 已知限制

- 陆地轮廓与河道取现代矢量，未复原各历史时期的海岸线与河道变迁。
- 地形高程取 Terrarium z5（约 4km/像素），只用于晕渲质感，不代表精细地形。
- 场景内两张快照之间的淡入淡出是镜头过渡，不表示疆界按直线推进。
- 书法字体缺字时自动回退到系统宋体。
