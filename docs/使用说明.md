# 使用说明

《中国五千年：山河流转，文明长卷》——22 分 57 秒，1920×1080，34 个场景。

## 交付内容

- `output/中国五千年_山河流转_1080p.mp4`：1920×1080，H.264 视频 + AAC 中文配音，
  自带画面字幕，另有可关闭的中文字幕轨与 34 个章节。
- `output/中文解说.wav`：配音音轨（22050Hz 单声道），可直接导入剪映等软件继续编辑。
- `output/中文字幕.srt`、`output/章节.ffmeta`、`output/解说文稿.txt`：文字交付件，
  由 `src/export_text.py` 从时间轴重出。
- `data/story.json`：34 场的分镜、解说、年代与要点。
- `data/timeline.json`：逐句音频的实测时间轴（决定每场时长与字幕节拍）。

**成片与配音音轨不进仓库**（体积超过 GitHub 单文件上限），按下面「重新生成」一节自行构建。

## 播放

直接用 QuickTime、VLC、IINA 等播放器打开 MP4。几点说明：

- 配音由云端 TTS 合成，非真人录音；成品音轨为本地母带处理后的单声道解说。
- 为保证讲解清楚，未叠加背景音乐。画面不是实拍，是程序绘制的地图动画。
- 部分播放器默认显示内嵌字幕轨。由于画面已带字幕，如出现重复字幕，请关闭播放器的字幕轨。
- 字幕句尾不带句号。画面已表达的 5 句「取舍说明」已从旁白、字幕与文稿中一并删除。

## 环境

- Python ≥ 3.12（本片在 3.13.12 上渲染），依赖见 `requirements.txt`
- Node.js（仅在重新下载素材时需要）
- 渲染过程会随包使用 imageio-ffmpeg 提供的 ffmpeg，无需另外安装

```bash
python -m pip install -r requirements.txt
```

## 重新生成

### 1. 素材

```bash
node scripts/download_assets.cjs      # 历史快照、陆地/河流矢量、字体、许可原文
node scripts/download_terrain.cjs     # 地形高程瓦片（z5，48 块）
```

两个脚本只补齐缺失文件，不覆盖已有文件；`download_assets.cjs` 会重新生成
`assets/sources.json`（来源 + sha256），可用于核对随包素材。

### 2. 自检

```bash
python src/map_scenes.py
```

校验各场景引用的快照年份是否存在、政权名是否真实存在于对应快照、城市坐标是否齐全，
末行输出 `CHECK PASS` 才算通过。改名、换年份后请先跑这一步，避免渲染时静默丢层。

### 3. 单帧预览（不需要配音）

```bash
python src/map_style.py --scene 15 --out work/预览.png     # 指定场景出一张静态图
python src/render_film.py --preview 7 12 17                # 某几场各取前 8 秒，出无声片段
python src/render_film.py --list                           # 列出场景与时长
```

### 4. 配音（可选）

仓库不含配音音轨。若已有 `output/中文解说.wav` 与 `data/timeline.json`，跳过本节。

用云端 TTS 重新合成（需自备 API Key，音色可用服务方预设或自传参考音克隆）：

```bash
python src/cloud_voice.py --provider siliconflow --key sk-xxx --voice <音色> --tag sh-a
python src/audio_master.py work/配音-cloud-sh-a            # 逐句响度对齐 + EBU R128
```

把 `work/配音-cloud-sh-a/中文解说-master.wav` 放到 `output/中文解说.wav`，
把该目录的 `timeline.json` 放到 `data/timeline.json`，再依次执行：

```bash
python src/cut_narration.py       # 若重新合成，旁白会带回被剪的 5 句，需再剪一次
python src/export_text.py         # 重出字幕 / 章节 / 解说文稿
```

> `src/cut_narration.py` 会直接改写配音与时间轴，运行前请先备份这三个文件。

### 5. 渲染全片

```bash
python src/render_film.py --force
```

- 渲染前会校验 `data/timeline.json` 的总时长与 `output/中文解说.wav` 是否一致，不一致直接报错。
- 逐场结果缓存在 `work/film/scene-XX.mp4`。**改过画面配置后必须加 `--force`**
  （或先清掉 `work/film/scene-*.mp4`），否则有缓存的场景会被跳过。
- 分镜编码成功后才从 `.partial.mp4` 改名成正式缓存，避免未完成文件被当作缓存复用。
- 约 8 分钟（34 场 / 2.1 万帧）；不要用同一工作目录并发运行多个渲染进程。

## 目录与职责

| 路径 | 说明 |
|---|---|
| `src/map_style.py` | 地图渲染器：底图着色、疆域色场、标注、装饰、逐帧推镜与合成；配色集中在文件顶部 `STYLE` |
| `src/map_scenes.py` | 34 场的图层/配色/城市/流线配置，与 `data/story.json` 同序；含 `SHAPES` 手绘示意范围 |
| `src/render_film.py` | 逐帧渲染 → 拼接 → 封装配音、字幕、章节 |
| `src/export_text.py` | 由时间轴导出字幕、章节、解说文稿 |
| `src/cloud_voice.py` | 云端 TTS 合成配音；产出到 `work/配音-cloud-<标签>/`，不覆盖现有配音 |
| `src/audio_master.py` | 配音母带：逐句 RMS 对齐 + ffmpeg loudnorm 两遍 |
| `src/cut_narration.py` | 一次性脚本：剪掉画面已表达的旁白并前移时间轴 |
| `scripts/` | 素材下载与校验 |
| `assets/` | 地图快照、矢量、高程瓦片、字体、许可原文、`sources.json` |
| `work/` | 渲染中间产物（缓存、日志、试听），可随时删除 |

画面标题使用 Ma Shan Zheng（马善政）书法字体，正文使用系统宋体，缺字按字符回退。

## 地图与史实边界

1. 本片是历史概览和教学式地图动画，不是历史疆界考证、逐年复原或现代标准地图。
2. 历史范围采用 Historical Basemaps 开放数据的选定快照，画面圆章标注所用年份。
3. 实际选用快照共 17 个：前 1000、前 500、前 300、前 200、前 100、200、400、600、700、
   800、1000、1200、1279、1600、1700、1800、1900 年。
4. 文化中心、诸侯位置、三国及交通路线为作者绘制的空间示意，不能量算疆域。
   数据集将多国合并为单一多边形时，用「就近分区」示意其势力范围，画面注明「分区示意」。
   数据集范围明显不符通行史实时，按通行画法手绘示意范围替代（`src/map_scenes.py` 的 `SHAPES`）：
   商、西周、春秋、战国秦与六国、统一后的秦、匈奴、北宋、南宋、金、西夏、辽、明；
   另从元的范围扣除朝鲜半岛，为清（1800 年）补入台湾与喀什。
   匈奴等游牧政权没有固定疆界，画成晕开的势力范围，不描边。
   所有疆域边界加了统一的手绘起伏，只为观感，不代表边界的真实走向。
   手绘范围已按通行画法（以谭其骧《中国历史地图集》为主要参照）做过一轮史实核对，
   用 56 个有明确归属的地点逐一检验（如盘龙城、曾国、上郡、九原、辽东郡、海南、邓州、
   沙州、黑水城、可敦城、宁夏镇、河套），并修正了不符之处。核对凭通行史实，未逐页比对原图；
   明代范围取约 1600 年形势，河套此时已不在明境内（明初至 1470 年代曾在明境内）。
5. 唐代以约 700 年与约 800 年两张快照做场景内衍化，不冒充盛唐最大版图；
   明代为约 1600 年的示意范围。
6. 数据源部分年份存在名称/年代错配（例如 `world_700` 的中国多边形被标为 `Sui Empire`），
   本片已知并作出标注，未当作精确史实。
7. 地图为东亚局部视窗，不是每个政权的完整疆域图；历史图层不应直接与现代国界等同。
8. 现代章节仅使用无国界陆地轮廓和城市联系，没有绘制现代主权范围或宣称标准地图审图状态。
9. 陆地轮廓与河道为现代参考线，未复原各历史时期海岸与河道变迁。
10. 历史色块淡入淡出是镜头过渡，不表示边界在两个年份之间按直线推进。
11. 正式出版、课堂严谨考证或商业公开发行之前，应由历史地理专业人员审校，并另行核对地图使用规范。

## 质量检查范围

脚本在渲染前校验分镜数量、快照存在性、政权名是否真实存在于对应快照、城市坐标是否齐全，
并校验时间轴总长与配音音轨时长一致；交付前检查 MP4 编码、分辨率、音轨、章节数与全片可解码性。

机器检查不等于真人审听或专家史料审校。实际结果以运行日志为准，不把未执行的检查写成通过。
